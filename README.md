# AWS OPERATIONS WORKSHOP BASIC SETUP

This repository contains the code for the basic infrastructure setup to work with AWS Operations Workshop.
The workshop is designed to help you learn how to operate and observe AWS services effectively.

## Workshop
The workshop is available at [AWS Operations Workshop](#link-is-missing).
Please clone or download the latest code from the repository to follow along with the workshop.

You can find the basic setup for different frameworks in the respective directories. The workshop is currently available for Pulumi.

## Available Frameworks
The basic setup is available for  
- [Pulumi](./pulumi-code) (TypeScript, npm)

Further basic setups are planned:
- AWS CDK (TypeScript)
- Terraform
